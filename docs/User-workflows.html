2. QA Planner / ผู้วางแผน

ใช้ Schedule สร้างและติดตาม Customer Audit (CS) กับ Internal Audit (IA)

สร้าง Customer Audit (CS)

  1. เปิด Schedule เลือก Month แล้วเลื่อนไปยังเดือนที่ต้องการ
  2. ตรวจป้ายกำกับวันหยุด/ข้อจำกัดก่อนสร้าง: Public Holiday ปิดทั้ง CS/IA; No Customer Audits และ Shutdown Plant ปิด CS
  3. กด New appointment หรือคลิกวันที่ แล้วเลือก Customer Audit
  4. กรอก Standard, Site, Customer, End Customer, Purpose, Target Package, Customer Name, QMS Host และช่วงวันที่ให้ครบ
  5. กด Save. หากยังไม่ครบ สามารถบันทึกเป็นร่างได้ การ์ดจะแสดง Incomplete Data สีแดงอ่อน พร้อมข้อมูลที่ขาด

สร้าง Internal Audit (IA)

  1. เลือกวันปกติ หรือวันที่กฎอนุญาต IA แล้วเปิดฟอร์ม Internal Audit
  2. กรอก 5 ช่องหลัก: Standard, Site, Audit Category, Area และ QMS Host พร้อมช่วงวันที่
  3. ใน Area เลือกหลายค่า หรือพิมพ์เพื่อสร้าง tag ใหม่; ค่าจะแสดงรวมโดยคั่นด้วย /
  4. กด Save แล้วตรวจรายละเอียดและสถานะบนการ์ด

แก้ไขและลบ

  1. คลิกการ์ดเพื่อตรวจรายละเอียด แล้วใช้ปุ่มดินสอเพื่อแก้ไข หรือถังขยะเพื่อลบ
  2. หากเป็นรายการหลายวัน ให้อ่านตัวเลือกว่าจะปรับเฉพาะวันหรือทั้งรายการก่อนยืนยัน
  3. ตรวจสีสถานะ: แดงไม่ครบ, ม่วงรายการใหม่, น้ำเงินรายการอัปเดต, เหลืองรอผล/ติดตาม, เขียวเสร็จสิ้น

3. QMS Host / ผู้รับผิดชอบการตรวจ

ใช้ Schedule ตรวจงานที่ได้รับมอบหมาย และบันทึกผลตรวจเมื่อดำเนินงานแล้ว

  1. ใน Schedule กรองด้วย QMS Host และ Site ของตนเอง ตรวจเดือน/ปีและช่วงวันที่ให้ถูกต้อง
  2. ตรวจประเภทการตรวจ, Customer (CS) หรือ Area (IA), Standard และรายละเอียดช่วงวัน
  3. หากวันหรือรายละเอียดไม่ถูกต้อง ให้ประสาน QA Planner หรือผู้รับผิดชอบแก้ไขตามกระบวนการของทีม
  4. เปิดการ์ดและเลือกไอคอน Audit Results เพื่อกรอกจำนวน Major, Minor, OFI, OBS และ Findings แยกตามไซต์
  5. ตรวจตัวเลขและไซต์ก่อนบันทึก รายการหลายวันอาจใช้ผลร่วมกันทั้งชุด; ใช้ส่วน NOTES ของวันเพื่อส่งต่อข้อสังเกต
ถ้าสถานะยังเป็น Pending Result ให้ติดตามผลที่ยังค้าง และทำตามขั้นตอนปิดงานของทีมเมื่อผลตรวจครบ
Checklist ก่อนวันตรวจ
  • ยืนยันวัน/ช่วงวัน ไซต์ ประเภทตรวจ Standard และผู้ประสานงานกับ QA Planner
  • สำหรับ IA ในวัน Shutdown Plant ยืนยันว่าไซต์ไม่ได้ถูกล็อก
  • หากข้อมูล Schedule ไม่ตรง ให้แจ้งผู้วางแผนก่อนแก้ข้อมูลต้นทาง

4. QA Admin / ผู้ดูแลข้อมูล

Manage ใช้ดูแล QMS Host ตัวเลือกในแบบฟอร์ม และกฎวันหยุดที่มีผลต่อ Schedule

จัดการ QMS Host และตัวเลือก

  1. เปิด Manage → QMS Host ค้นหาตามไซต์/แผนกก่อนเพิ่มหรือแก้ไขรายชื่อ
  2. ใช้ New QMS Host เพื่อเพิ่มผู้รับผิดชอบ หรือแก้ข้อมูลที่ได้รับอนุมัติให้ถูกต้อง
  3. เปิด Manage → Options เพื่อดูแล Site, Standard, Customer, Purpose, Target Package หรือ Audit Category
  4. ตรวจชื่อซ้ำและการสะกดก่อนเพิ่ม/ลบ/เรียงลำดับ เพราะตัวเลือกเหล่านี้ปรากฏในแบบฟอร์มของผู้ใช้

จัดการวันหยุดและข้อจำกัด

  1. เปิด Manage → Holidays เลือกปีด้วยลูกศรหรือช่องกรอกปี
  2. คลิกวันหรือเลือก Add Date Range Rule แล้วเลือกระหว่าง Public Holiday, Shutdown Plant หรือ No Customer Audits
  3. สำหรับ Shutdown Plant เลือกไซต์ใน Affected Sites ที่ต้องล็อก (เริ่มต้นไม่มีไซต์ถูกเลือก) แล้วตรวจไซต์/ช่วงวันที่
  4. กด Save Status เพื่อบันทึก; ใช้ Reset to Normal Day เพื่อล้างกฎของวันที่เลือก
  5. ปัจจุบันยังไม่มีตัวนำเข้าวันหยุดจาก Excel/CSV; สร้างหรือแก้กฎจากหน้าปฏิทินโดยตรง กฎนี้ไม่เปลี่ยนนัดหมายที่มีอยู่แล้ว

สรุปผลของกฎวันที่

Public Holidayปิดทั้ง Customer Audit (CS) และ Internal Audit (IA)
No Customer Auditsปิด CS แต่อนุญาต IA
Shutdown Plantปิด CS; อนุญาต IA ยกเว้นไซต์ที่เลือกล็อก
ก่อน Save: ตรวจชนิดกฎ · วันเริ่ม/สิ้นสุด · ชื่อกฎ · Affected Sites (Shutdown Plant) แล้วตรวจป้ายกฎบนปฏิทินหลังบันทึก

5. ผู้ติดตามผลและผู้จัดทำรายงาน

ค้นหาข้อมูลที่ต้องการก่อน แล้วส่งออกเฉพาะชุดข้อมูลที่ผ่านตัวกรอง

  1. เปิด Table แล้วใช้ช่องค้นหาและตัวกรอง Audit Type, Sites, Standards, Customers, QMS Hosts และ From/To
  2. เรียงข้อมูลจากหัวคอลัมน์; กด Reset filters เมื่อต้องการเริ่มค้นหาใหม่
  3. ตรวจจำนวนผลลัพธ์และขอบเขตวันที่ แล้วกดปุ่มดาวน์โหลด Excel เพื่อส่งออกแถวที่กรองอยู่เป็น `.xlsx`
  4. เปิด Summary เพื่อตรวจยอดตามไซต์/ปี และใช้ปุ่ม Export ของส่วนรายงานที่ต้องการ
  5. เปิด History เพื่อค้นหาการเปลี่ยนแปลงด้วย Action, Entity และช่วงวันที่ หากพบรายการผิดปกติให้ประสาน QA Admin
ไฟล์ส่งออกอาจมีข้อมูลลูกค้าและรายละเอียดการตรวจ ควรตรวจตัวกรองก่อนดาวน์โหลดและจัดเก็บตามแนวทางขององค์กร
ตรวจไฟล์ก่อนส่งต่อ
  • ตรวจตัวกรองและช่วงวันที่ก่อน Export
  • เปิด .xlsx ตรวจหัวคอลัมน์ จำนวนแถว และตัวอย่างไซต์อย่างน้อยหนึ่งรายการ
  • ส่งต่อไฟล์ตามสิทธิ์หน่วยงาน เพราะอาจมีข้อมูลลูกค้าและรายละเอียดการตรวจ

6. แก้ปัญหาเบื้องต้น

ไม่พบรายการตรวจเดือน/ปี, Site, QMS Host และตัวกรอง ล้างตัวกรองแล้วค้นหาอีกครั้ง
การ์ดสีแดงเปิดการ์ด อ่านฟิลด์ที่ขาด เติมข้อมูล แล้วบันทึก
สร้าง CS ไม่ได้ตรวจ Public Holiday, No Customer Audits, Shutdown Plant และช่วงวันที่
IA ถูกบล็อกตรวจ Public Holiday หรือว่า Site ถูกล็อกใน Shutdown Plant
ข้อมูลหายหลัง Refreshตรวจข้อความบันทึก/การเชื่อมต่อก่อนลองบันทึกซ้ำ แจ้งผู้ดูแลพร้อมเวลาที่เกิดเหตุ
Export ไม่ตรงตรวจตัวกรอง ช่วงวัน ปี และจำนวนแถวก่อนดาวน์โหลดใหม่
หากต้องแจ้งปัญหา ให้ระบุหน้าที่ใช้งาน เวลาโดยประมาณ ไซต์ และขั้นตอนที่ทำ พร้อมภาพหน้าจอที่ปกปิดข้อมูลลูกค้า/ข้อมูลลับ

1. Getting started

Open the application in a standard Microsoft Edge or Google Chrome window. Sign in with your User ID and password. After login, the app opens Schedule at the current month and year.

  1. Choose a tab: Schedule for the calendar, Table for records, Summary for yearly totals, Manage for system options, or History for the change log.
  2. The calendar covers UTL1, UTL2, UTL2A, UTL2B, UTL3, UTL3A, and UTL3T. Confirm the correct site before creating or editing a record.
  3. The login session normally survives a page refresh. If the login screen returns, the session may have expired or browser site data may have been cleared; sign in again.
  4. On shared devices, open the user menu and select Sign out when you finish. InPrivate/Incognito mode may not retain the session after its window closes.

2. QA Planner — schedule Customer and Internal Audits

Use Schedule to create, review, and maintain Customer Audit (CS) and Internal Audit (IA) appointments.

Create a Customer Audit (CS)

  1. Open Schedule, choose Month, and navigate to the month you need.
  2. Check the day cell and its restrictions before booking. Public Holiday blocks both CS and IA; No Customer Audits and Shutdown Plant block CS.
  3. Select New appointment or click a date, then choose Customer Audit.
  4. Enter Standard, Site, Customer, End Customer, Purpose, Target Package, Customer Name, and QMS Host. Set the From/To dates and verify the range.
  5. Save the appointment. Incomplete required data can be saved as a draft; the card shows Incomplete Data in red. Open the card and complete the missing fields.
  6. Confirm the card appears on the expected day/site. Refresh the page to confirm the change persisted.

Create an Internal Audit (IA)

  1. Choose a normal day or a restricted day that allows IA at the selected site.
  2. Choose New appointment or click the date, then select Internal Audit.
  3. Complete the five core fields: Standard, Site, Audit Category, Area, and QMS Host. Confirm the date range too.
  4. In Area, select multiple existing tags or type to create a new one. Values are displayed together with / between them.
  5. Save and inspect the calendar card. If it is red, reopen it and fill the missing fields.
  6. No Customer Audits permits IA. Shutdown Plant permits IA only for sites not selected as locked. Public Holiday blocks both types.

Edit or delete an appointment

  1. Use filters such as Site, Customer, Standard, Audit Type, or QMS Host to find the record.
  2. Open the card to review it. Use the edit control to change details or the delete control to remove it.
  3. For a multi-day appointment, read the scope prompt carefully and confirm whether the change applies to one day or the whole series.
  4. After saving, verify the day, site, card status, and details. If the change disappears after refresh, report the save issue before trying again.

3. QMS Host — review assignments and enter results

Use Schedule to view audits assigned to you. Filter by your QMS Host name and site, then check the month/date range.

  1. Review date, site, audit type, Standard, and Customer (CS) or Area (IA). Contact the QA Planner if the assignment or details are wrong.
  2. Before the audit, confirm the calendar day allows the appointment. For IA on a Shutdown Plant day, check whether your site is locked.
  3. Open the appointment and choose Audit Results (clipboard/results icon) to enter findings.
  4. Select the correct site and enter the result counts for Major, Minor, OFI, OBS, and Findings. Check the values and site before saving.
  5. For multi-day appointments, confirm whether the result applies to the entire series. Use the day’s Notes field for relevant handover details.
  6. Review the status after saving. If it remains Pending Result, follow up on the outstanding information and use the team’s process to close the work.
Before the audit
  • Confirm the date, site, audit type, Standard, and contact with the QA Planner.
  • Report incorrect source details to the planner instead of changing them without authorization.
  • If results do not appear after refresh, check for an error and contact the planner/admin before duplicating the entry.

4. QA Admin — maintain hosts, options, and holidays

Manage QMS Hosts

  1. Open Manage → QMS Host.
  2. Filter/search by Site, Standard, or Department before changing a record.
  3. Use New QMS Host to add an approved contact; verify name, role, site, and department.
  4. Check that the record is still in use before deleting or changing it. Confirm the updated record appears in the expected list.

Manage form options

  1. Open Manage → Options and choose the option group, such as Site, Standard, Customer, Purpose, Target Package, or Audit Category.
  2. Add, edit, delete, or reorder approved values. Check spelling and duplicates first.
  3. Remember that dropdown changes affect future choices; review how existing appointments display the value before removing it.

Manage holidays and restrictions

  1. Open Manage → Holidays. Choose a year with the arrows or enter a four-digit year.
  2. Click a calendar day or choose Add Date Range Rule, then choose the rule type and date range.
  3. For Shutdown Plant, select only the sites that should be locked under Affected Sites. The list is unchecked by default; verify it before saving.
  4. Enter a clear rule name/note and check start/end dates, type, and affected sites. Choose Save Status.
  5. Use the Public Holidays card to review the chronological holiday list, then edit/delete the intended entry. Use Reset to Normal Day to remove a selected day’s restriction.
  6. Excel/CSV holiday import is not available in this build. Add rules in the calendar. Existing appointments are not automatically edited or deleted by a holiday rule.

5. Report users — search, export, and review history

Search and export

  1. Open Table. Search or filter by Audit Type, Sites, Standards, Customers, QMS Hosts, and From/To dates.
  2. Select a column heading to sort. Use Reset filters to clear the current search.
  3. Check the result count, filters, and date range. Select the Excel export button to download the filtered rows as .xlsx; allow the browser download.
  4. Open the workbook and check headers, row count, and a sample site before sharing.
  5. Open Summary to review yearly/monthly site totals and findings. Select the intended year and export the relevant section.

Review the change history

  1. Open History and filter by Action, Entity, search text, and date range.
  2. Review entries for appointment changes, result changes, QMS Host/options, or holiday/restriction changes.
  3. If something looks unexpected, note the time, record, and change, then contact the QA Admin/system owner.
Exported workbooks may contain customer names and audit details. Store and share them according to company data handling rules.
