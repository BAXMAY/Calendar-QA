# UTAC QA Calendar (QMS-CASS) — คู่มือขั้นตอนการทำงานแยกตามผู้ใช้งาน

เอกสารนี้จัดขั้นตอนตามหน้าที่ที่ผู้ใช้ทำในระบบ เพื่อให้ทำงานประจำวันได้เป็นลำดับ คำใน **ตัวหนา** คือชื่อเมนูหรือปุ่มที่ปรากฏในแอป

> **หมายเหตุเรื่องสิทธิ์:** บทบาทในเอกสารนี้เป็นแนวทางแบ่งงาน (QA Planner, QMS Host และ QA Admin) ไม่ใช่การยืนยันว่าระบบซ่อนเมนูหรือจำกัดสิทธิ์ตามบทบาท หน้าจออาจแสดงเมนูเดียวกันแก่ผู้ใช้หลายกลุ่ม ให้ปฏิบัติตามสิทธิ์และขั้นตอนอนุมัติของหน่วยงาน

## 1. เริ่มต้นใช้งานสำหรับทุกคน

1. เปิด UTAC QA Calendar (QMS-CASS) ด้วย Microsoft Edge หรือ Google Chrome ในหน้าต่างปกติ
2. กรอก User ID และ Password แล้วกด **Sign in** ระบบจะเปิดหน้า **Schedule** ของเดือนและปีปัจจุบัน
3. ใช้เมนู **Schedule**, **Table**, **Summary**, **Manage** และ **History** เพื่อไปยังหน้าที่ต้องใช้
4. การเข้าสู่ระบบคงอยู่เมื่อรีเฟรชหน้า หากต้องการจบการใช้งาน ให้เปิดเมนูผู้ใช้แล้วเลือก **Sign out** โดยเฉพาะบนเครื่องที่ใช้ร่วมกัน
5. ตรวจสอบไซต์ที่เกี่ยวข้อง ระบบครอบคลุม `UTL1`, `UTL2`, `UTL2A`, `UTL2B`, `UTL3`, `UTL3A` และ `UTL3T`

## 2. ขั้นตอนของ QA Planner / ผู้วางแผน

### วางแผน Customer Audit (CS)

1. เปิด **Schedule** เลือกมุมมอง **Month** แล้วใช้ลูกศรเลื่อนไปยังเดือนที่ต้องวางแผน
2. ตรวจสอบวันหยุดและข้อจำกัดบนช่องวันที่ก่อนสร้างรายการ: `Public Holiday` ปิดทั้ง CS/IA; `No Customer Audits` และ `Shutdown Plant` ปิด CS
3. กด **New appointment** หรือคลิกวันที่ แล้วเลือก **Customer Audit**
4. เลือกช่วงวันเริ่ม/สิ้นสุด และกรอกข้อมูล CS ให้ครบ: **Standard**, **Site**, **Customer**, **End Customer**, **Purpose**, **Target Package**, **Customer Name**, **QMS Host** และช่วงวันที่ที่ถูกต้อง
5. กด **Save**. หากยังขาดข้อมูล ระบบยังให้บันทึกเป็นร่าง แต่จะแสดงสถานะ **Incomplete Data** สีแดง ให้เปิดรายการและเติมช่องที่ระบบระบุ
6. ตรวจสอบตำแหน่งและรายละเอียดการ์ดในปฏิทิน หากต้องแก้รายการ ให้เปิดการ์ดและใช้ปุ่มแก้ไข

### วางแผน Internal Audit (IA)

1. ใน **Schedule** เลือกวันปกติ หรือวันที่ข้อจำกัดอนุญาต IA
2. กด **New appointment** หรือคลิกวันที่ แล้วเลือก **Internal Audit**
3. ระบุช่วงวันและกรอก 5 ช่องหลัก: **Standard**, **Site**, **Audit Category**, **Area** และ **QMS Host**
4. ใน **Area** เลือกได้หลายรายการ หรือพิมพ์เพื่อสร้าง tag ใหม่ รายการจะแสดงรวมโดยคั่นด้วย ` / `
5. กด **Save** แล้วตรวจการ์ด หากข้อมูลไม่ครบ ให้เปิดการ์ดและเติมช่องที่ขาด
6. `No Customer Audits` อนุญาต IA; `Shutdown Plant` อนุญาต IA เฉพาะไซต์ที่ไม่ได้เลือกล็อกไว้; `Public Holiday` ไม่อนุญาตทั้งสองประเภท

### ดู แก้ไข หรือลบรายการ

1. ใช้ตัวกรอง **Site**, **Customer**, **Standard**, **Audit Type**, **QMS Host** หรือเงื่อนไขอื่น เพื่อลดรายการที่แสดง
2. เลือกการ์ดเพื่อตรวจรายละเอียด; ใช้ปุ่มดินสอเพื่อแก้ไข และปุ่มถังขยะเพื่อลบ
3. สำหรับรายการหลายวัน อ่านตัวเลือกขอบเขตก่อนยืนยันว่าจะแก้หรือลบเฉพาะวัน หรือทั้งรายการ
4. สถานะการ์ดช่วยติดตามงาน: แดง = ข้อมูลไม่ครบ, ม่วง = รายการใหม่ที่ข้อมูลครบ, น้ำเงิน = รายการที่อัปเดต, เหลือง = รอผล/ติดตาม, เขียว = เสร็จสิ้น

## 3. ขั้นตอนของ QMS Host / ผู้รับผิดชอบการตรวจ

### ตรวจตารางที่ได้รับมอบหมาย

1. เปิด **Schedule** แล้วกรองด้วย **QMS Host** และ **Site** ของตนเอง ตรวจช่วงเดือน/ปีให้ถูกต้อง
2. ตรวจวัน เวลา/ช่วงวันที่ ประเภทการตรวจ ลูกค้า (CS) หรือ Area (IA) และ Standard
3. หากรายละเอียดหรือผู้รับผิดชอบไม่ถูกต้อง ให้แจ้ง QA Planner หรือผู้มีหน้าที่แก้ไขในหน่วยงาน และแก้ในระบบตามขั้นตอนที่ได้รับอนุมัติ
4. ตรวจการ์ดสีแดงเพื่อดูข้อมูลที่ยังขาด และประสานผู้วางแผนให้เติมข้อมูลก่อนวันตรวจ

### บันทึกผลตรวจ

1. เปิดการ์ดนัดหมายที่เกี่ยวข้อง แล้วเลือกไอคอน **Audit Results** (ไอคอนคลิปบอร์ด/ผลตรวจ)
2. เลือกไซต์และบันทึกจำนวน **Major**, **Minor**, **OFI**, **OBS** และ **Findings** ตามผลตรวจ
3. ตรวจตัวเลขและไซต์ให้ถูกต้องก่อนบันทึก ผลของรายการหลายวันอาจใช้ร่วมกันทั้งชุดนัดหมาย
4. ใช้ส่วน **NOTES** ในรายละเอียดของวันเพื่อบันทึกข้อสังเกตหรือข้อมูลส่งต่อที่เกี่ยวข้อง
5. ตรวจสถานะหลังบันทึก หากยังเป็น **Pending Result** ให้ติดตามผลที่ค้าง; เมื่อปิดงาน ให้ทำตามกระบวนการปิดสถานะของทีม

## 4. ขั้นตอนของ QA Admin / ผู้ดูแลข้อมูล

### จัดการ QMS Host

1. เปิด **Manage → QMS Host**
2. ค้นหา/กรองรายชื่อด้วยไซต์หรือแผนกก่อนแก้ไข
3. ใช้ **New QMS Host** เพื่อเพิ่มผู้รับผิดชอบ หรือแก้ข้อมูลชื่อ บทบาท ไซต์ และแผนกให้ตรงกับข้อมูลที่ได้รับอนุมัติ
4. ตรวจรายการที่ใช้งานอยู่ก่อนลบหรือเปลี่ยนค่า เพื่อไม่ให้ข้อมูลอ้างอิงในงานใหม่ผิดพลาด

### จัดการตัวเลือกในแบบฟอร์ม

1. เปิด **Manage → Options** แล้วเลือกกลุ่มข้อมูลที่ต้องการดูแล เช่น Site, Standard, Customer, Purpose, Target Package หรือ Audit Category
2. เพิ่ม แก้ไข ลบ หรือเรียงลำดับตัวเลือกตามความจำเป็น
3. ตรวจตัวสะกดและความซ้ำซ้อนก่อนบันทึก การเปลี่ยนตัวเลือกมีผลกับรายการที่ผู้ใช้เลือกได้ในอนาคต; ตรวจข้อมูลเดิมที่บันทึกในนัดหมายด้วย

### จัดการวันหยุดและข้อจำกัด

1. เปิด **Manage → Holidays** แล้วเลือกรายปีด้วยลูกศรหรือกรอกปี 4 หลัก
2. คลิกวันที่บนปฏิทิน หรือเลือก **Add Date Range Rule** แล้วเลือกชนิดกฎ:
   - **Public Holiday** — ปิดการสร้างทั้ง CS และ IA
   - **No Customer Audits** — ปิด CS แต่อนุญาต IA
   - **Shutdown Plant** — ปิด CS และปิด IA เฉพาะไซต์ที่กำหนด
3. สำหรับ **Shutdown Plant**, เลือก **Affected Sites** ที่ต้องล็อก (ค่าเริ่มต้นไม่มีไซต์ถูกเลือก) แล้วตรวจรายชื่อก่อนบันทึก
4. ระบุชื่อ/หมายเหตุและช่วงวันที่ ตรวจสอบวันเริ่ม/สิ้นสุดและชนิดกฎ แล้วกด **Save Status**
5. เลือกการ์ด **Public Holidays** เพื่อดูรายการวันหยุดตามลำดับเวลา แก้ไขหรือลบรายการที่ต้องการ; ใช้ **Reset to Normal Day** เพื่อล้างกฎของวันนั้น
6. ปัจจุบันยังไม่มีการนำเข้าวันหยุดจาก Excel/CSV ให้เพิ่มกฎผ่านปฏิทินหรือ **Add Date Range Rule** โดยตรง กฎวันหยุดไม่แก้ไขหรือลบนัดหมายเดิม

## 5. ขั้นตอนของผู้ติดตามผลและผู้จัดทำรายงาน

### ค้นหาและส่งออกข้อมูล

1. เปิด **Table** ใช้ช่องค้นหาและตัวกรอง เช่น **Audit Type**, **Sites**, **Standards**, **Customers**, **QMS Hosts**, **From/To**
2. คลิกหัวคอลัมน์เพื่อเรียงข้อมูล และใช้ **Reset filters** เมื่อต้องการเริ่มค้นหาใหม่
3. ตรวจจำนวนผลลัพธ์และตัวกรองให้ตรงกับขอบเขตรายงาน
4. กดปุ่มส่งออก Excel เพื่อดาวน์โหลดรายการที่ตรงกับตัวกรองปัจจุบันเป็น `.xlsx`; อนุญาตการดาวน์โหลดในเบราว์เซอร์
5. เปิด **Summary** เพื่อดูยอดตามช่วงเวลา/ไซต์ ใช้ตัวเลือกปีและปุ่มส่งออกของหน้าสรุปตามรายงานที่ต้องการ

### ตรวจสอบประวัติ

1. เปิด **History** แล้วกรองด้วยคำค้น **Action**, **Entity** และช่วงวันที่
2. ตรวจรายการสร้าง แก้ไข ลบผลตรวจ เปลี่ยน QMS Host/ตัวเลือก หรือเปลี่ยนวันหยุด
3. หากพบรายการผิดปกติ ให้บันทึกวันที่ รายการ และการเปลี่ยนแปลงที่พบ แล้วประสาน QA Admin/ผู้ดูแลระบบ

## 6. ส่งต่องานและตรวจสอบก่อนจบวัน

- QA Planner ตรวจรายการสีแดงและรายการใหม่/อัปเดตที่ต้องยืนยันวันและผู้รับผิดชอบ
- QMS Host ตรวจตารางตรวจที่ได้รับมอบหมาย บันทึกผลและหมายเหตุที่จำเป็น และแจ้งรายการที่รอปิดผล
- QA Admin ตรวจคำขอแก้ข้อมูลหลักและกฎวันหยุด โดยยืนยันไซต์และช่วงวันที่ก่อนบันทึก
- ผู้ทำรายงานตรวจตัวกรองและช่วงเวลา ก่อนดาวน์โหลดหรือส่งต่อไฟล์ Excel
- ใช้ **History** ตรวจสอบการเปลี่ยนแปลงเมื่อจำเป็น
- เมื่อใช้เครื่องร่วมกัน ให้เลือก **Sign out** หลังทำงานเสร็จ
